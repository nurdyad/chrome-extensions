Connect your Chrome profile

In the extension, open Others → Desktop companion. Copy its extension ID here, save, then copy the pairing key back into that page.

Replacing the key disconnects Chrome. Pair again with the new key. Only one Chrome profile connects at a time.
Make it yoursLeave blank to disable. Example: Alt+Shift+Space. Avoid the extension's Alt+Shift+H shortcut; the desktop shortcut works even outside Chrome.

Full-screen apps, Spaces and protected windows may take precedence over always-on-top. Restore the toolbar anytime using its tray/menu-bar icon.
