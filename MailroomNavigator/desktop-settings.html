Connect the desktop toolbar

Optional 2.0 preview for Windows and macOS. Your extension continues to work without it.

1. Approve this extension in the desktop app

Open Desktop Settings. Copy this extension ID into its Chrome extension ID field, then save.

2. Pair this Chrome profile

In Desktop Settings, select Copy pairing key, then paste it below. Only one Chrome profile connects at a time.

Checking connection…

After connecting, open Navigator on a BetterLetter tab and select a practice. Choose that tab explicitly in the desktop toolbar. Changing practice requires selecting the updated target again.

Requires Chrome 116 or newer. Desktop navigation uses the extension's existing settings; no database or Linear credentials are copied to the desktop app.
